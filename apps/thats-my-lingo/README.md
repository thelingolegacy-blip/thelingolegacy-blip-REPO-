# That's My Lingo ⭐️ — Casino Studio

Premium purple-and-gold social casino experience for The Lingo Legacy.

## Current AppDeploy source
- App: `that-s-my-lingo-casino-studio-2xntye`
- Visual direction: purple, gold, crimson accents, cinematic motion
- Game: 5×3 reels, 20 paylines, LINGO symbols, Wild Rush, Free Spins, Bonus Room
- Economy: Demo Coins / virtual-only rewards; no real-money wagering or cash-out
- Responsive targets: mobile, desktop, large-screen/TV browser layouts

## Platform roadmap
- Web: React + Vite
- Mobile: Flutter client consuming shared game contracts
- Edge: Cloudflare Workers/KV/D1
- Identity/data: Firebase
- Deployment: AppDeploy / Netlify / Cloudflare
- TV: LG webOS browser/TV layout optimization; native webOS packaging remains a separate build artifact.
